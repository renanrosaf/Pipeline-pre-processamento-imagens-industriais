# pipeline-inspecao-qualidade-opencv
Projeto focado em Visão Computacional para a Indústria 4.0. Utiliza Python e OpenCV para aplicar técnicas de redução de ruído, operações morfológicas e detecção de bordas em um lote de imagens de peças metálicas, padronizando os dados para futuros modelos de Inteligência Artificial.
